02阶段 A：把录屏变成"可挑的字幕稿"

这一步的目的不是加字幕，是把声音变成文字，好让你用眼睛挑段——而不是拖时间轴反复听一小时。

  1. 新建草稿，把录屏拖进剪映
    录屏本身的要求：连续、不中断、不切场景。一次直播录一整段，切成十几段反而不好处理。
  2. 识别字幕
    顶部 文本 → 智能字幕 → 识别字幕 → 开始识别。5 分钟素材约 30 秒出结果。
  3. 改掉三类错字（只改这三类，别通读）
    人名（主播名、队友 ID、嘉宾名）、游戏术语（技能名、装备名、地图名）、他的口头禅。这三类恰恰是切片里最关键的字，识别错了会让观众出戏。
    其余错字不用管——你后面不加新字幕，识别稿只是给你自己看的。
  4. 导出 SRT
    右上角 导出 → 格式选 SRT（不是视频）→ 导到你能找到的地方，比如桌面。

技巧：直接在字幕面板里改，别在时间轴上改

双击时间轴上的字幕条容易误拖动。用左侧「文本」面板里的字幕列表逐条点选，改起来快得多。

03阶段 B：挑段——这是唯一没法自动化的环节

双击 start.bat，把视频和 SRT 分别拖进两个框。页面会列出带编号的所有句子（5 分钟约 60–90 句）。

怎么从一个列表里挑出一条片子

不要从头读到尾然后"看哪句好笑"。用这个顺序，效率高得多：

  1. 先找结尾，倒着往前推
    一条切片必须结束在一个笑点上，不能说完就断。所以先找"最炸的那一句"，它要么当开头钩子，要么当结尾。找到它，这条片子的骨架就有了。
  2. 再往前找"起因"
    笑点前面通常有一句交代背景的话（"我跟你们说昨天遇到个人……"）。从这一句开始选，否则观众不知道你在笑什么。
  3. 连续选中，不要跳选
    从"起因"到"笑点"整套选下来，中间别跳。跳着选会把两件不相干的事拼在一起，成片会跳。
    操作：点第一句 → 按住 Shift 点最后一句，整段选中。
  4. 设钩子
    把笑点那句再点一次「设钩」。它会同时出现在开头 0–2 秒，并从原位置被挖掉（不会播两遍）。
    这是抖音切片的规矩：第 1 秒就给最好笑那句，然后倒回去讲事情怎么发生的。

长度红线：45–75 秒

页面底部会实时显示选中段的时长。超过 90 秒基本没救——完播率会崩，平台不给推。宁可砍掉铺垫，也不要为了"讲完整"而拉长。

一条 40 秒左右的切片，通常就是 25–35 句。把整场 90–100 句全选上、做成三四分钟，那是一条完整录屏，不是切片。

挑段的三个判断标准（多剪 20 条才有的直觉，先背下来）

标准怎么判断
有反转听完有一句"啊？"的反应。平铺直叙的段子再好笑也别选。
不看前情也懂把这段单独拿给你妈看，她能笑 → 成立。需要"上周那把游戏"作为前提的 → 不成立。
有反应镜头笑点之后他那 2 秒的表情/沉默，比台词更值钱。选段时务必把笑点后面多包一句进去，别在笑点处直接切断。

04阶段 C：生成草稿（三个选项怎么选）

页面底部有几项设置，只有一项需要你动脑：

设置怎么选
版式发抖音就选「竖屏 9:16 · 模糊背景」。它会做三件事：
① 画布 1080×1920；② 把同一段画面放大 + 模糊 + 压暗，铺满整屏当背景（不再是死黑）；③ 原来的横屏画面按原比例放在中间偏上（中心在 44% 高度，左右两个人都不裁）。
位置分配：上方 13% 留给标题/钩子大字，中间 28%–60% 是画面，下方 76% 放新字幕。
「竖屏分栏」是黑底版，视频贴顶、下面一整块黑，比较硬；「跟素材走」= 横屏直出，只在不需要 9:16 时用。
叠加我自己的字幕竖屏版式（模糊背景/分栏）下可以勾。新字幕落在画面下方的空白区，跟画面里的原字幕空间上是分开的，不会叠在一起。
只有「跟素材走」的横屏满屏版式下不要勾——那时新字幕只能压在画面上，必然跟原字幕打架。
抹掉画面里的原字幕默认勾上。你的录屏底部烧死了一行旧字幕（画面 83%–90% 高度处），加了自己的大字幕后它就重复了。
勾上会把这条横带原位补平：程序先自动认出字幕在哪、有多宽，再用四周的像素往里插值（ffmpeg delogo），把字抹掉。画面尺寸、比例一点都不变，人物不会被切、画面也不会变矮。
代价：视频要重编码一次（5 分钟约 1–2 分钟），结果缓存在 uploads\_clean\，同一条片子再生成不用重等。
如果某条片子字幕位置特别、抹不干净，就取消勾选，然后在剪映里把新字幕挪开旧字幕的位置。
背景模糊只在「模糊背景」版式下起作用（切到别的版式会自动灰掉）。改的是最底下那层背景的糊度，中间讲事情的画面一直是清晰的，怎么调都不影响看清人脸。
五档：不糊（只放大，背景等于第二份实画面）/ 轻（还看得出轮廓，适合想让背景有点内容的时候）/ 中 / 强（默认，只剩色块，最不抢戏）/ 极强（一团色雾，接近纯色块）。
拿不准就用默认的「强」。成片里觉得背景太糊、太假，往上调一档到「中」；觉得背景里的人和动作太抢眼，往「极强」调。
前后留白保持 0.2。只在"句子开头被截掉半个字"时才调大到 0.4。调太大反而会把上一句的尾巴带进来。
接缝淡化保持 0.12 秒。这是"切换不咔"的关键——每段开头音量从 0 渐入、结尾渐出，把爆音和突兀感消掉。填 0 可以关掉。
转场默认选「不加」。直播切片大量用硬切，切点靠音效和花字盖住才自然。只有当你选的几段时间上跳跃很大（比如从游戏画面跳到三小时后的反应）时，才在那一处用「叠化」或「闪白」。
一次生成只给一种转场，所以别指望它自动分辨该用哪个。
爆点句号填你觉得最炸的那几句的编号，逗号分隔，比如 42,88,136。填了以后程序自动做：① 爆点句前面切出 0.2 秒、音量拉 0（静音留白）；② 画面推到 1.12 倍再回正（推近）；③ 在时间轴上把那一小段单独切出来（你在剪映里一眼能看到）。
留空也能生成，只是这两件事要你在剪映里手动做（见阶段 D）。一条片子填 2–4 个就够，别每个笑点都推。
提示保持「标记轨」。提示会变成时间轴上的静音占位音频，文件名就是提示内容（「12.4s_爆点-唱片 刮擦」），位置精确到 0.1 秒，画面里完全看不见，听到那里把占位删掉、原位拖入真音效即可。
选「标记轨 + 画面钩子标签」会额外在片头 1.2 秒贴一个橙色标签——会盖住一点画面，只有想在预览区也看到提醒时才选；「只画面标签」是旧行为。
草稿名写成你能认出来的：日期 + 内容关键词，比如 1120-狗懒子。别用"切片1""测试"。

点「生成剪映草稿」，日志出现 ✅ 完成 就成了。下面会显示一张版面预览图——先看这张图，确认字幕没挡脸、画面没黑边，再打开剪映。

想重新生成时，换个名字

同名会覆盖。如果某个草稿你已经在剪映里剪了一半，重新生成时务必改个名，否则辛苦剪的包装会被冲掉。另外草稿一旦在剪映里保存过，文件会被加密，程序就读不回来了——这是正常现象，不影响使用。

05阶段 D：剪映里那 20 分钟（你缺的就是这节）

先做一件事：生成草稿成功后，网页上会多出一个按钮 「打开配乐 / 音效 / 花字 / 标题建议清单」。点它，会打开一份和你这条片子对得上的清单——BGM 选哪套、第几秒放什么音效（连搜索词和音量都写了）、花字写什么字用什么样式、发布标题和封面大字直接复制。把它放在旁边，边看边剪，不用当场想。

打开剪映，草稿列表里点开你的片子。你会看到几条轨道，从上到下大概是：

施工标记·导出前删我
一条静音音频轨，每个提示是一小段占位音频，文件名就是提示：「12.4s_爆点-唱片 刮擦」「0.0s_钩子-最炸这句放最前」← 位置精确到 0.1 秒，画面里完全看不见
花字
空轨，等你加
主字幕
空轨（原片自带字幕，所以没生成）
主视频
你的片段，4 段左右

为什么提示不在画面里，而是在一条音频轨上

之前试过把「这里放刮擦」「这里留白」直接打在画面上——几张橙色标签一贴，人脸和字幕全被盖住，最后只能留一个。改成网页清单吧，又得在浏览器和剪映之间来回对时间码。

现在换成占位音频：剪映时间轴上的音频片段会显示素材文件名，所以你会看到一串小色块，名字就是「12.4s_爆点-唱片 刮擦」。三件事同时成立——画面干净、位置精确、剪映里直接读得到。

用法：听到那个位置觉得该加音效，就把这一小段占位删掉，在原位拖入真音效；也可以全部加完之后，把整条轨一次性删掉。

先说一个反直觉的结论：切点"生硬"，九成不是缺转场

人耳对声音突变极其敏感：上一段话尾的呼吸声突然掐断、下一段直接以半句话开始，听着就是"咔"一下。而人眼对硬切几乎无感——抖音上绝大多数切片全是硬切。

所以顺序是：① 接缝淡化（已在生成时自动做好，120ms）→ ② 音效盖住切点 → ③ 最后才考虑转场。加一堆叠化反而会显得像 PPT。

新版：爆点可以交给程序自动做（阶段 B 里填「爆点句号」）

生成草稿时在页面上填一栏 爆点句号（如 42,88,136），程序会自动完成两件事：① 在爆点句前面切出 0.2 秒、把这一段音量拉到 0（静音留白，画面照走）；② 画面 0.14 秒推到 1.12 倍、维持 0.45 秒、再 0.45 秒回正。

这样第 2 步「做留白」就不用自己切刀了，第 3、4 步只剩「挑音效 + 挑花字样式」——那两件是审美，机器替不了。没填这一栏时，下面第 2 步照旧手动做。

第 1 步：确认开头 3 秒，再看程序已经替你做了什么

提示不再往画面上贴了。草稿里那条「施工标记」音频轨上，每个提示都是一段静音占位音频，文件名就是提示内容：钩子在 0.0 秒、爆点在它该落的秒数、收尾留白在最后一段前。你只要照着这条轨往下做，不用再切到浏览器去对时间码。

程序已经做好在时间轴上长什么样你要检查什么
钩子前置 施工标记轨上 0.0 秒处有一段 0.0s_钩子-… 的静音占位 听一句：有没有一秒就抓住人？如果是"那个……我跟你们说"，说明钩子选错了句，回阶段 B 重选。
爆点留白 爆点句前面有一小段音量被拉到 0 的片段 不用动。想更狠就把这一小段拉长到 0.4 秒，观众会以为卡了。
爆点推近 那一小段上有两个菱形关键帧（缩放 1.12） 不用动。觉得夸张就删掉关键帧，觉得不够就把它改成 1.18。
原字幕裁切 画面下部被切掉 18%，切口下面是模糊背景 看一眼底部那条带：旧字幕抹干净了没有、有没有留下半行字。没干净就取消「抹掉画面里的原字幕」，在剪映里手动把新字幕挪开。
模糊背景 最底下的「背景模糊」轨，整条铺满 如果某一段背景太亮抢眼，选中那段，把不透明度往下拉到 60% 左右。

程序不知道中间哪句话好笑

它只能按你填的爆点句号干活。所以你在剪映里听一遍的时候，心里要有一张「还有哪里该动手」的地图：那些程序没标的地方，就是你自己加音效和花字的地方。

第 2 步：做留白（先做这个，因为影响后面所有音效的位置）

  1. 找到【留白】标记的位置，把播放头挪到它前面 1 秒处。
  2. 选中视频轨，按 Ctrl+B 切断（在留白前 1 秒切一刀，爆点第一帧再切一刀）。
  3. 选中中间那一小段，右键 → 音量 → 拉到 0。或者直接按 Ctrl+Delete 删掉这一小段（连画面一起没了，更狠，适合翻车现场）。
  4. BGM 轨也要在此处切开、静音，否则只静了人声，音乐会露馅。

留白多长？0.6–1 秒。一条片子只用一次

短于 0.5 秒观众感觉不到，长于 1.5 秒会以为视频卡了。整条只做一次，用第二次就失效了——观众的耳朵会对静音产生预期。

第 3 步：加音效（6–10 个，多了就吵）

点顶部 音频 → 左侧 音效素材 → 搜索框里打关键词 → 试听 → 点右下角 + 加到时间轴。

场景搜这些词怎么用
翻车 / 意外 唱片刮擦、黑胶 停顿 和「乌鸦飞过」叠着放，各 0.3 秒。单个不够好笑，两个一起才有那味。
尴尬 / 无语 乌鸦、冷场 放在他说完话后的沉默处，音量压低（−18dB 左右），是背景不是主角。
爆点 / 反转 低音 轰鸣、Boom、叮 压在爆点第一帧。音量 −8dB，要能听见但不能盖住台词。
转场 / 注意力 咻、whoosh 钩子跳切回正文的那一帧（约 2 秒处），用来标记"时间倒流"。
打字 / 强调 打字机 花字出现时同步，一个花字配一声，别连着用。

音效两条铁律

① 音量必须压到 −8 ~ −12dB。剪映里选中音效 → 右上角「音量」，默认 100 就是 0dB，拉到 30–40% 差不多。盖住人声是新手最常见的错误。

② 音效要对齐"动作帧"，不是"台词帧"。他说到笑点的那一个字，音效就在那一帧响，早半秒晚半秒都会让人觉得"廉价"。

第 4 步：加花字（3–5 个，这是你唯一需要"设计"的地方）

因为原片自带字幕，花字是你唯一能做的视觉包装，所以它值得认真做——但也正因为只有它，数量必须克制。

  1. 点顶部 文本 → 左侧 花字，选一个带入场动画的样式（推荐黄色/白色描边一类，别选彩虹渐变）。
  2. 点右下角 + 加到时间轴，会落在"花字"轨上。
  3. 双击文字框，只写 2–4 个字：离谱、？？？、完蛋、我裂开。整句话绝不放进花字。
  4. 拖时长到 0.6–1.2 秒，动画播完就消失。挂 3 秒以上观众会烦。
  5. 位置：画面左上方或右上方，绝不压人物脸，也不压原字幕带（原字幕在画面 72%–79% 高度，花字放 15%–30% 那一条带最安全）。

放哪四个位置？

① 钩子那 2 秒（标题式花字，让人一秒知道这视频讲什么）；② 爆点（哈哈哈哈 或 ？）；③ 反应镜头（他愣住的时候放 人已麻）；④ 结尾（引导关注，或放个悬念词）。中间那些平淡的段落一个都别放。

第 5 步：配 BGM

  1. 点 音频 → 音乐素材 → 搜情绪词而不是曲名：搞笑、滑稽、轻松、悬疑。喜剧切片首选轻快的拨弦/马林巴类，节奏快但不抢戏。
  2. 拖进时间轴，选中 → 音量拉到 15–25%（约 −20dB）。检验方法：闭上眼睛只听，你要能听清每个字。
  3. 做音乐反转（可选但很有效）：在爆点处把 BGM 切断，接一首风格完全相反的（正经的、悲伤的、婚礼进行曲）。画面在翻车、音乐在庄严 —— 反差本身就是笑点。

第 6 步：收尾——删掉施工标记轨、做封面

选中「施工标记·导出前删我」整条删除。它只是一串静音占位音频（画面里本来就看不见），留着的坏处是音轨变乱、以后自己分不清哪条是 BGM。

然后点 导出 旁边的 设置封面：固定一个版式，以后不再改——大脸特写 + 一行 8 字以内的黄底黑字，要能在一屏缩略图里看清。定死它，每次只换文字。

06阶段 E：导出与发布

导出参数一次定死，以后不再纠结。每次重新选一遍是纯粹的浪费：

项值
分辨率1080P（你的源是 1910×1080，导出 1080P 足够，别开 4K——体积翻三倍，平台还会二次压缩）
帧率30fps（源是 30 就跑 30，别升 60）
码率选「推荐」或「更高」都行，不要选"自定义"乱填
格式MP4 / H.264（平台通吃）

发布时只做三件事：标题写一句钩子（和开头第一句一致，别写"分享一个搞笑片段"这种废话）、话题带 #主播名 + 2 个内容相关词、封面用你做好的那张。别在发布页重新调封面，会变模糊。

07出问题了：按层排查，别跳层

新手最容易犯的错是一上来就改审美——觉得不好看，立刻去调花字颜色。但问题往往在下面两层。

所有样式集中在一个文件顶部，改完重新生成即生效，不用重新识别字幕。

一次只改一个参数

这是排查问题的通用原则，改样式也一样。同时改三个，出了问题你不知道是哪个引起的。

09接下来 10 条片子怎么练

工具能替你干"找、切、对轴、排工程"，替不了"哪句好笑、音效放哪、花字什么时候出"。后者只能靠量堆出来，但有顺序。

阶段练什么达标标志
第 1–3 条只练"选段"。包装从简：3 个音效 + 2 个花字 + BGM，别多。剪完自己回看一遍不觉得尴尬
第 4–6 条练"留白"和"音效对帧"。每条都必须做一次爆点前的真空。朋友看的时候在爆点处笑了
第 7–8 条练"音乐反转"。试一次错位配乐（翻车画面 + 庄严音乐）。能说清自己哪条的反转起作用了、为什么
第 9–10 条练"钩子"。同一个素材，试三种不同的开头第一句，对比数据。能预判哪句当钩子完播率最高

每条剪完记三个数：时长、你自己看完几遍、发布后 3 秒完播率。

十位数之后，这三个数会告诉你所有事——比任何教程都准。

10两条不能越过的线

① 授权

直播切片需要主播或公会授权（抖音、快手都有官方切片授权入口）。做得越好越容易被盯上——这条不是形式问题，是账号能不能活下去的问题。

② 判断力

工具能替你"找、切、对轴、排工程"，替不了"哪句好笑、音效放哪、花字什么时候出"。这是整套流程里唯一必须你自己做的部分，也是最值钱的部分。别指望工具替你想清楚，它只会忠实执行你给的选段。

日常只需记住三件事：① 双击 start.bat，黑窗口别关；② 原片有字幕就别勾"叠加我自己的字幕"；③ 切片长度 45–75 秒，一个笑点一条。

有问题发我日志（uploads\_server.log）或截图，比描述现象快得多。
