# punch-craft-jianying · 技术说明（dev-notes）

把《直播切片剪辑手册》里的参数固化成代码，**生成剪映能直接打开的草稿**。
你不用学剪辑操作，只要做判断：选哪几句、哪个是爆点。

> **新手先看 [guide.html](guide.html)**（完整流程 + 剪映里那 20 分钟怎么做 + 症状对照表）。
> 本文件是技术说明：参数在哪、命令行怎么用、有什么限制。
> **本文中的 `uploads/`、`preview/` 等路径都相对项目根目录**（本文件在 `docs/` 下）。

| `fix_audio.py` + **`fix-audio.bat`** | **草稿没声音时一键修**：删掉写坏音量关键帧，换回剪映原生淡入淡出 |

**注意：`uploads/` 里是视频副本，剪映草稿直接引用它，删了草稿会提示素材丢失。**

## 二、用法 A：网页界面（推荐，不用敲命令）

1. 在剪映里给录屏识别字幕 → 导出 **SRT**（见下面第 1 步）
2. **双击 `start.bat`**，浏览器会自动打开一个页面（黑色窗口别关，那是服务）
3. 页面里两个框：一个放视频、一个放 SRT —— **直接拖进去**，或点框选文件
4. 出现带编号的句子清单后：点一下选中，**按住 Shift 点**选一整段；要当开头钩子的那句点「设钩」
5. 填个草稿名，选 **版式**（发抖音就选第一个）：
   - **竖屏 9:16 · 模糊背景**（推荐）—— 1080×1920 画布：同一段画面放大+模糊+压暗铺满整屏当背景，
     原横屏画面按原比例放在**中间偏上**（中心在 44% 高度）。上方 13% 放标题/钩子大字，
     下方 76% 放新字幕，三段互不打架，也不会把左右两个人裁掉
   - **竖屏分栏 · 黑底新字幕在下** —— 视频贴顶、下面一整块死黑放字幕，比较硬，只有想要纯黑底时才用
   - **跟素材走 · 横屏满屏** —— 画布比例跟原片一致，横屏直出，不加第二套字幕时最干净

   版式右边还有 **「背景模糊」**：只有「模糊背景」这一档用得上（切到别的版式会自动灰掉）。
   它改的就是最底下那层背景的糊度，**中间讲事情的画面一直是清晰的**，调多少都不影响看清人脸。
   六档：`不糊`（只放大）/ `很轻` / `轻`（默认，还看得出轮廓）/ `中` / `强`（只剩色块）/ `极强`（一团色雾）。
   拿不准就先用默认，成片里觉得背景太糊抢戏就调轻一档。

   再往右有个 **「抹掉画面里的原字幕」**（默认勾上）：录屏底部烧死的那行旧字幕会跟新字幕重复，
   勾上就把那条横带**原位补平**（ffmpeg delogo 用四周像素插值），画面比例完全不变、不裁任何画面。
   代价是要把视频重编码一次（5 分钟约 1–2 分钟），结果缓存在 `uploads/_clean/<原名>-clean.mp4`，
   同一条片子再生成就直接复用。
   想加自己的字幕就勾「叠加我自己的字幕」（**原片已经有字幕时别勾，会打架**）
6. 点「生成剪映草稿」→ 日志出现 `✅ 完成`，页面上会多出一张**版面预览图**，先看排版对不对
7. 打开剪映，草稿就在列表里

**草稿到底存在哪？**

- 剪映里看：打开剪映 → 首页草稿列表，名字就是你填的那个
- 磁盘上看：`%LOCALAPPDATA%\JianyingPro\User Data\Projects\com.lveditor.draft\<草稿名>\`
  （`%LOCALAPPDATA%` 一般是 `C:\Users\<你的用户名>\AppData\Local`，把这个变量原样粘到资源管理器地址栏即可）
  其中 `draft_content.json` 就是工程文件
- 工具生成成功时会把这个完整路径打印在日志里，直接复制就能在资源管理器里打开

> 生成失败时，工具会**自动删掉那个没写完的草稿目录**，所以剪映里不会多出打不开的空项目。

> 页面只在你电脑内部访问（`127.0.0.1:8765`），视频不会上传到任何服务器。
>
> **那个黑色窗口不能关。** 它就是服务本身，关掉网页就传不了文件、也生成不了草稿。
> 用完最后再关；窗口标题已经写成「这个窗口别关」提醒你。

**上传失败怎么查（按顺序）：**

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 页面顶部出现红条「本地服务已断开」 | 黑窗口被关了 / 进程退出了 | 重新双击 `start.bat`，再刷新页面 |
| 框里写「连不上本地服务」 | 同上 | 同上 |
| 框里写「收到 0 字节」 | 服务还在，但请求体没发出来 | 再拖一次；仍失败就点页面底部「自检」链接 |
| 拖进去没反应 | 拖的是文件夹，或文件被占用 | 换「点框选文件」的方式 |
| 想看到底发生了什么 | —— | 看 `uploads/_server.log`，每个请求和报错都记在里面 |

## 三、用法 B：命令行（想批量/自动化时用）

### 第 1 步：让录屏有字幕（在剪映里做）

1. 录屏拖进剪映 → 顶部「文本」→「智能字幕」→ 开始识别
2. 识别完 → 右上角导出字幕 → 选 **SRT**
3. 得到 `录屏.srt`

> 剪映自带的识别对中文口语已经很准，这一步不用装任何 AI 模型。

### 第 2 步：看带编号的字幕清单

```bash
cd punch-craft-jianying
.venv/Scripts/python.exe slice_by_text.py list --srt 录屏.srt
```

输出大概长这样：

```
编号   起止时间                    文字
1      12.30s → 15.80s      我跟你们说这个人真的很离谱
2      16.00s → 19.20s      我昨天在游戏里遇到他
...
```

**这就是「在文字上挑片段」的全部操作——不用在时间轴上盲切，看着文字点编号就行。**

### 第 3 步：选段 + 指定钩子，生成草稿

```bash
.venv/Scripts/python.exe slice_by_text.py build ^
    --video 录屏.mp4 ^
    --srt 录屏.srt ^
    --pick 18,19,20,21 ^
    --hook 25 ^
    --name 嘴硬翻车
```

- `--pick`：要保留的句子编号，逗号分隔。**连续挑中的句子会自动合并成一整段**（中间不切、不留缝，所以不会重复）
- `--hook`：把这一句提到最前面当「前置高潮」，**原位置会被自动挖掉**，不会播两遍
- `--pad`：只在整段选区的首尾留白，默认 0.2
- `--layout`：`auto`（横屏素材→`blur`、竖屏素材→`fill`）、`blur` 竖屏+模糊背景（推荐）、`split` 竖屏分栏、`fill` 跟素材走
- `--sub`：加新字幕。**默认不加** —— 原视频已经烧了字幕时，加了一定会打架
- `--fade`：每段首尾音量渐入渐出，默认 `0.12` 秒。**切点听着"咔"就靠它消掉**，填 `0` 关闭。用的是剪映**原生「音量淡入淡出」**（素材属性里的那一项），不是音量关键帧
- `--transition`：段间转场，默认不加。可选 `叠化` / `闪白` / `闪黑` / `故障` / `模糊`（转场挂在前一段尾部，段长 < 1.2 秒时自动跳过，避免吃掉正文）
- `--punch`：**爆点句号**，逗号分隔（如 `42,88,136`）。填了以后每一处自动做两件事：
  ① 在爆点句前面切出 0.2 秒、把这一段音量拉 0（**静音留白**，画面照走）；
  ② 画面 0.14 秒推到 1.12 倍 → 维持 0.45 秒 → 0.45 秒回正（**推近**）。
  前面没有空隙时自动跳过留白并提示你，不会把上一句尾音切掉。
- `--keep-subs`：**保留**画面里烧死的原字幕（默认会把它原位抹掉，画面比例不变）
- `--hint`：提示放哪。`marker`（默认）把提示做成时间轴上的静音占位音频，文件名就是提示内容，画面里完全看不见；`all` 再加一个画面内钩子标签；`one` 只放画面钩子标签（旧行为）
- `--bg-blur`：背景模糊强度 `0–100`（就是剪映「模糊」特效那根滑杆的量程），默认 `35`。
  `0` 只放大不糊、`20` 很轻、`35` 轻、`55` 中、`80` 强、`100` 极强。**只影响背景那一轨，主视频不糊**
- `--title`：`blur` / `split` 版式下画面上方的标题文字

生成完，草稿会自动出现在剪映的草稿列表里，名字就是你 `--name` 填的。
同时会在 `preview/` 下生成一张**版面预览图**，不开剪映就能先看排版对不对。

### 第 4 步：在剪映里收尾

打开草稿后你要做的只有四件事：

1. 看**「施工标记·导出前删我」**这条音频轨 —— 它是一串静音占位音频，**文件名就是提示**：
   `12.4s_爆点-唱片 刮擦`、`0.0s_钩子-最炸这句放最前`、`28.8s_收尾-留白淡出`。
   位置精确到 0.1 秒，画面里完全看不见。听到那里觉得该放音效，把占位删掉、原位拖入真音效即可
2. 加完音效后整条删掉（**导出前一定要删**，虽然它是静音，留着会让音轨变乱）
3. 在「花字」轨加 3–5 个花字
4. 配 BGM，导出

## 四、参数在哪改

全部集中在 `make_draft.py` 顶部的「参数区」：

```python
LAYOUT = "auto"         # auto / blur（竖屏+模糊背景，推荐）/ split（竖屏分栏）/ fill（跟素材走）
BG_ALPHA = 0.62         # 模糊背景压暗程度（0.62 ≈ 压暗 38%，太亮会抢前景）
BG_BLUR = 35            # 背景模糊强度 0–100（= 界面里的「背景模糊」下拉：0 不糊 / 35 轻 / 100 极强）
CUT_ORIG_SUBS = True    # 抹掉画面里烧死的原字幕（delogo 原位补平，不裁画面）
SUB_SIZE = 9.0          # 主字幕字号
SUB_BORDER_W = 25.0     # 黑描边粗细
SUB_MAX_LINE = 9        # 单行最多几个字
FANCY_Y = 0.05          # 花字位置
FANCY_BG_COLOR = "#FFD84D"   # 花字底色
```

字幕位置（`SUB_Y`）、视频位置（`VIDEO_Y`）、标题位置（`TITLE_Y`）**不要手改** ——
它们由 `apply_layout()` 按版式和素材方向算出来：
`blur` 把视频中心放在 44% 高度、标题 13%、字幕 76%；`fill` 把字幕放在画面 60% 处（避开原字幕所在的 72%–79%）；
`split` 把视频顶到最上方、字幕放进下方黑区的 42% 处。

改完重跑脚本，下次生成的草稿就全是新样式。**这就是"模板"的意义：调一次，以后都省了。**

## 五、已知限制

1. **剪映 11.5 把草稿加密了。**
   已保存过的草稿 `draft_content.json` 是密文，所以**"拿现成草稿当模板批量换素材"做不到**。
   本工具走的是另一条路：从零生成明文草稿，剪映能读，保存时才加密。

2. **烧在画面里的字幕去不掉。**
   那是画面像素，只能靠 AI 擦除或重新压制。三条路：
   ① 不加新字幕，直接用原字幕（默认，最省事）；
   ② 竖屏分栏，新字幕放到下方黑区，原字幕缩得很小、空间上分开；
   ③ 用 ffmpeg 把那条带模糊+压暗再重新压制（画质有损，一次几分钟）——本工具没内置，想用可以自己改 `clean_subs.py`。

3. **不能自动导出。**
   `pyJianYingDraft` 的自动导出依赖剪映 6 及以下版本的界面控件，新版剪映已不适用，所以最后一步要手动点导出。

4. **字幕字号可能需要微调。**
   剪映内部的字号刻度和界面显示的 px 不是一一对应。如果打开后发现字幕偏大或偏小，改 `SUB_SIZE`（9 → 8 变小，→ 10 变大），重跑一次即可。

5. **第一次打开如果报"资源加载失败"**，通常是剪映在下载字体/特效缓存，关掉重开一次。

## 六、草稿没有声音？怎么修

**症状**：草稿在剪映里打开，画面、字幕、转场都对，但**完全没有声音**（音量 100% 也没声）。

**原因**：早期版本用「音量关键帧」做段首段尾的渐入渐出。剪映把关键帧里的 `0.0 / 1.0` 读成 `0% / 1%` 音量，
四段全被压到几乎静音 —— 所以是**整条片子没声**，不是个别切点没声。

**修法（两条任选）**：

1. **修现有草稿**（不用重新挑句子）：
   完全退出剪映 → 双击 **`fix-audio.bat`** → 直接回车（默认修最新那个草稿）→ 重新打开剪映。
   它会删掉所有音量关键帧、把音量恢复 100%，并改用剪映原生淡入淡出（4 段各 120ms）。
2. **重新生成**：界面里照原样再点一次「生成剪映草稿」即可（脚本已改成原生淡入淡出，不会再坏）。

> 顺序很重要：**先退剪映，再修**。剪映开着的时候改文件没用 —— 它退出时会把内存里的旧内容存回去。


### 另一个常见问题：bat 一闪就关 / 满屏乱码

说明 bat 文件被编辑器改成了 UTF-8/LF 换行。cmd 只认 **GBK/ASCII + CRLF**。
这几个 bat 现在都是纯 ASCII + CRLF，重下/重拷时注意别用"另存为 UTF-8"。

## 七、配乐清单里都写了什么

每次生成草稿，程序还会在 `preview\<草稿名>-配乐清单.html` 产出一份建议清单（网页上也有按钮直接打开）。
它基于这条片子的**实际时间轴**给建议，不是通用模板：

| 区块 | 内容 |
|---|---|
| ① BGM | 三套方案（轻快搞笑 / 鼓点紧张 / 前轻快后悲情），每套给了剪映搜索词、BPM、音量、适合场景；外加音乐反转四招和版权提醒 |
| ② 音效 | 逐条列时间点（钩子落点、每个爆点、每个切点、结尾）+ 放什么 + **搜什么词** + 音量 |
| ③ 花字 | 3–5 处，**建议文字直接从原话里截**（不用你想文案）+ 用哪种样式 + 放画面哪 |
| ④ 标题 / 封面 | 5 条发布标题 + 一句封面大字，直接复制 |

它不会替你觉得哪句好笑。**填了「爆点句号」，花字和音效就锁在爆点上；不填就按句长、语气、位置猜，清单里会明确告诉你这是猜的。**
