# punch-craft-jianying

**把直播回放，变成一条能直接发的抖音切片。**

读剪映导出的 SRT → 按编号选段 → 自动拼接、加前置钩子 → 生成 **9:16 竖屏剪映草稿**（模糊背景、独立字幕轨、画面里烧死的原字幕原位抹除）→ 附一份配乐/音效/花字/标题清单。全程离线，素材不出本机。

> Turn a stream VOD + a JianyingPro SRT into an editable vertical JianyingPro draft, with a BGM/SFX/caption plan. Windows only, fully offline.

---

## 它替你做了什么

```
直播回放.mp4  ┐
              ├─→ 选段（你按字幕编号挑）→ 自动剪、自动拼 → 剪映草稿 → 你加音效导出
字幕.srt      ┘                                     └→ 配乐清单 + 时间轴施工标记
```

| 手工做 | 它做 |
|---|---|
| 在 300 句字幕里挑笑点 | 列出**带编号**的全部句子，你报编号（或点选） |
| 一句句切、拖时间轴对齐 | 自动算切点、留 0.2 秒气口、拼成一条轨 |
| 手动把高潮句挪到片头 | `--hook` 指定一句，自动前置 |
| 竖屏排版：背景、字幕位置、字号 | 一键出 9:16 版面（含背景模糊档位、标题位、字幕位） |
| 画面里原有的字幕挡新字幕 | 自动认出字幕横带，`delogo` 原位补平（**不改画面比例、不裁切**） |
| 想 BGM 配什么、声音放多大 | 输出一份 HTML 清单：3 套 BGM 方案 + 每个时间点放什么音效、搜什么词、多少音量 + 花字 + 标题 |
| 记住"第 12.4 秒要放刮擦" | 做成时间轴上的静音占位音频，**文件名就是提示**，画面零遮挡 |

## 需要什么

- **Windows 10/11**（Mac 不支持，草稿路径写死在 Windows 的 `%LOCALAPPDATA%`）
- **剪映专业版**（桌面版，不是手机版）
- **Python 3.9+**（开发与实测环境为 3.13）
- 不需要单独装 ffmpeg —— `imageio-ffmpeg` 自带

---

## 三步装好

```bash
git clone https://github.com/junxingzao-wyh/punch-craft-jianying.git
cd punch-craft-jianying
```

或者点页面右上角 **Code → Download ZIP**，解压后双击 `install.bat`（效果一样，不想装 git 就用这个）。

1. 双击 **`install.bat`** —— 自动建虚拟环境、装依赖（走国内镜像）
2. 双击 **`start.bat`** —— 浏览器自动打开 `127.0.0.1:8765`（**那个黑窗口别关，它是服务**）
3. 拖视频、拖字幕，按界面上的按钮走

网页界面打不开时，双击 **`start-cli.bat`** 走命令行问答版。

## 第一次用，先做这一步

**工具不生成字幕，字幕要用剪映做。** 这是唯一必须手工的环节：

> 剪映里导入回放 → 文本 → 智能字幕 → 识别字幕 → 右上角「导出」→ 导出 SRT

导出时顺手改一下错别字（尤其人名、方言词），后面选段全靠它。

然后：**拖 `回放.mp4` + `回放.srt` 进页面 → 挑句子 → 点生成 → 打开剪映，草稿已经在列表里了。**

详细操作见 **[docs/guide.html](docs/guide.html)**（从挑段到成片的完整 6 步，含症状对照表）。

## 已知限制

1. **只支持 Windows**。Mac 版剪映的草稿路径完全不同，代码里写死的是 `%LOCALAPPDATA%\JianyingPro\User Data\Projects\com.lveditor.draft`
2. **剪映别随便升级**。草稿格式是逆向出来的，升级可能改结构导致打不开。升级后草稿异常，重新生成即可
3. **字幕要自己做**。没有内置语音识别
4. **选段要人挑**。哪句好笑只有人知道，工具只负责挑完之后的所有事
5. 视频画幅是**横屏原比例居中 + 模糊背景补上下**，不是把横屏裁成竖屏（裁了会切掉人脸）

## 常见问题

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 页面顶部红条「本地服务已断开」 | `start.bat` 的黑窗口被关了 | 重新双击 `start.bat`，刷新页面 |
| 生成后剪映里没有草稿 | 剪映开着时不会刷新列表 | 关掉剪映再打开 |
| 草稿里素材显示丢失 | 删了 `uploads/_clean/` 里的中间文件 | 重新生成一次 |
| **整条片子没声音** | 旧版用音量关键帧做淡化，剪映读成 0% | 退出剪映 → 双击 `fix-audio.bat` → 回车 |
| 字幕位置偏了 | 原片字幕不在默认高度 | 改 `clean_subs.py` 里的 `detect_band`，或直接留空自己加 |

更多见 [docs/guide.html](docs/guide.html) 的「症状对照表」。
